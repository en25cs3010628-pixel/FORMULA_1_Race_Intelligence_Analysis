# FORMULA 1: Race Intelligence Analysis Report (2010–2026)

## Project Overview
This data analytics project analyzes Formula 1 race performance, reliability patterns, and driver/constructor trajectories to deliver actionable strategic insights for technical teams and race management[cite: 1].

## Problem Statement
Inconsistent race telemetry tracking and fragmented DNF data hinder real-time strategic decision-making and mechanical risk mitigation across multi-season F1 campaigns[cite: 1].

## Tools Used
* **Tableau Public:** Used for dynamic data visualization, building an interactive 5-chart dashboard grid, and crafting a 9-scene story presentation.
* **Dataset:** `F1_Race_Intelligence_2010_2026.csv` containing multi-season race results, telemetry, driver origins, and DNF classifications[cite: 1].

## Key Visualizations & Findings
1. **Global Circuit Distribution:** Geographic mapping identifying international race footprint and venue clustering across seasons.
2. **Driver Reliability & DNF:** Technical failure analysis highlighting major mechanical causes (engine, gearbox) and collision frequencies by constructor.
3. **Championship Trajectory & Leaderboards:** Performance dynamics tracking constructor point accumulation dominance and top-tier driver standings over time.

## Project Deliverables
* **Live Interactive Dashboard:** [https://public.tableau.com/app/profile/nikunj.tare/viz/FORMULA_1_Race_Intelligence_Analysis/Formula1NarrativeStory?publish=yes]
* **Project Files:** The published `Formula 1 Narrative Story` workbook on Tableau Public featuring the complete 9-scene narrative arc[cite: 1].
